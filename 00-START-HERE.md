## 🚀 Quick Start (3 Steps)

### Step 1: Get Your API Key (2 minutes)
```
1. Visit: https://blackbox.ai
2. Sign in with GitHub/Google
3. Settings → API Keys → Create
4. Copy your key
```

### Step 2: Configure (1 minute)
```bash
# Windows
.\setup-blackbox.bat

# Unix/Mac/Linux
chmod +x setup-blackbox.sh
./setup-blackbox.sh

# Or manually
npm install
npm run build
```

### Step 3: Set Environment Variable (1 minute)
```env
# Edit .env file and add:
BLACKBOX_API_KEY=your_api_key_here
```

### Step 4: Start Using (NOW!)
```bash
npm start
# or
npm run start:http
```
